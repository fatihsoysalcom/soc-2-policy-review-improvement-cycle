# SOC 2 Policy Review Improvement Cycle

This example simulates a SOC 2 policy review process, treating non-compliant findings as 'failed tests' that drive continuous improvement. It demonstrates how to define security policies, test against them using simulated data, and generate actionable insights for enhancing an organization's security posture rather than just reporting failures.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
